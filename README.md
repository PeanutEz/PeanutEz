## 💡 What I Do

- **Backend:** Building RESTful APIs with NestJS (Node.js + TypeScript) and C#
- **Frontend Basics:** Working with JavaScript, HTML and CSS
- **Database:** Writing and optimizing SQL queries on PostgreSQL (including Neon serverless Postgres) and Oracle (indexing, execution plans, reducing query time)
- **Caching:** Using Redis to speed up responses and reduce database load
- **API Testing:** Testing and documenting APIs with Postman
- **Basic DevOps:** Containerizing applications with Docker and deploying to servers
- **Version Control:** Managing code with Git (branching, merging, resolving conflicts)
